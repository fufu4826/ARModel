## Account Compatibility

Existing password verification, environment precedence, hashing, rate limiting,
and session authorization remain in place. An existing installation without an
admin username uses `admin` with its existing password. A configured
`ADMIN_USERNAME` takes precedence over `admin_username` in the private config.
New local installations choose a username during first setup. No actual private
configuration, password, API key, or environment file was edited for this review.
Changing a username does not make a weak password secure; this remains a single
administrator account, not a multiple-user account management system.
